# deck/checkpoint1/ — the 15-slide pitch deck (required submission artifact)

> **Summary:** `deck.html` is the editable source (self-contained HTML, one `<section class="slide">`
> per slide, 1280×720 pages, no external assets); `deck.pdf` is the committed submission artifact,
> regenerated by `deck/checkpoint1/build.sh` (headless Chrome). Hard limits from the rules: **PDF only · ≤ 15
> slides · ≤ 20 MB** — build.sh verifies all three and fails otherwise. Every number in the deck is
> sourced from checkpoint/1.md, docs/EXPLAINER.md, docs/adr/ or evidence/ — never hand-computed.
> To edit at 3am: change deck.html, run `deck/checkpoint1/build.sh`, commit both files.

## Regenerate the PDF

```bash
deck/checkpoint1/build.sh
```

Requires Google Chrome (default macOS path). Any Chromium works:
`CHROME=/path/to/chromium deck/checkpoint1/build.sh`.

## Editing rules

- **One `<section class="slide">` = one page.** Never exceed 15 — judges stop reading at slide 15,
  and build.sh enforces the count.
- **Do not invent a number.** Every figure must trace to `checkpoint/1.md`, `docs/EXPLAINER.md`,
  an ADR, or `evidence/*.txt`. If you change a headline number, check it against the live service
  first (`tools/ch`) — the deck quotes the re-verified numbers from checkpoint/1.md, not the stale
  ones some older docs carry (see checkpoint §B6 item 1).
- Self-contained: inline CSS only, system fonts, no scripts, no external assets. It must render
  offline and print deterministically.
