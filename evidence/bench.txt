*** THIS QUERY SET IS OUR RECONSTRUCTION, NOT THE OFFICIAL SET. ***
The official benchmark query set was never released. These 13 queries are the
shapes the problem statement names — peak AND average concurrency, at minute /
hour / day grain, with dimension filters (platform, country, content, video
type) — plus the partial-filter shape (platform IN two values) that the hour
tier explicitly does NOT serve, so its documented minute-scan fallback is
measured rather than guessed. Grain and parameter choices are ours.

method: warm-up discarded (idle Cloud service measured at 29.3 s on first
query); then per query 1x EXPLAIN indexes=1 + 3 timed runs with
use_query_cache=0 AND use_query_condition_cache=0; median reported. Latency is
the server-side elapsed_ns from X-ClickHouse-Summary; wall ms includes network
from the operator laptop to ClickHouse Cloud. 'stable' = all 3 runs returned
byte-identical answers. Every run is labelled with
log_comment='bench:<query>:run<N>:bench-20260801T165403Z' and its query_id is
listed in section 2, so every number below is auditable in system.query_log.
