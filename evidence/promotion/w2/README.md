## Tooling caveat, verified first (per the W2 brief)

`main`'s `tools/ch` ignores the `TARGET` env var — `TARGET=local` is assigned unconditionally at
line 9; only a positional `-c` reaches Cloud. Verified:

```
$ tools/ch -c "SELECT currentDatabase(), version()"
sonyliv 26.2.1.525                                      ← Cloud, correct
$ TARGET=cloud tools/ch "SELECT currentDatabase(), version()"
default 26.7.1.1315                                     ← LOCAL — TARGET silently ignored
```

Consequence: **every Cloud read below used `tools/ch -c`** (or raw `curl` with the `.env`
credentials for multi-statement files). `tools/reconcile.sh` is unaffected — it reads its own
`TARGET` env and passes `-c` itself (line 23). W1's fix is not cherry-picked here, per the brief.
