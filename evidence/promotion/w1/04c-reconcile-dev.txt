Note on 2026-07-26 11:31: naive reads 0 while the model reads 5. That is TAIL_S —
the model credits one cadence past the last event, which at the very end of the
dataset extends beyond max(event_timestamp). Expected, not a discrepancy.

The gap is backgrounded and paused time. Heartbeats stop while backgrounded
(0.047/min vs 4.72/min active) but SURVIVE a pause (0.756/min), so gaps alone
cannot find paused time — it is excluded explicitly. See ADR 0007.
