    max single COMBINATION, not the group total. Measured at the peak minute

        SONY_ANDROID_TV         275                     12

    GRAIN first, then running-sum — same order of operations as 80_content.sql.

    tables and no OTLP ingest path (verified: zero otel tables across all
    databases), so the OTLP-fed "SonyLIV pipeline health" dashboard of
    docs/OBSERVABILITY.md lives on the LOCAL stack only. The hosted twin built
    below reads the same three signals cloud-natively (v_cc_watermark,
    system.query_log, gate-run detection by read-set).

truth=2,887 vs serving=2,917 because the ADR 0009 same-second-resume fix was in
