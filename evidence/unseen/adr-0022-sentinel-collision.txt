§2 THE FIX — cube_level in the key (sql/50_hour_agg.sql, ADR 0022)
--------------------------------------------------------------------------------
- cc_hour_agg gains cube_level UInt8: bit 0 platform real, bit 1 country real,
  bit 2 content_id real; 7 = full grain, 0 = grand total. ORDER BY
  (platform, country, content_id, cube_level, hour) — the marker is in the key,
  so a rollup row is structurally not a content row and ReplacingMergeTree can
  never collapse the two.
- The canonical INSERT carries the fan-out mask g through as cube_level in
  every GROUP BY and window PARTITION. The PUBLISH_EXTRACT markers and the
  literal ARRAY JOIN anchor line tools/publish.sh sed-templates are unchanged.
- Serving views expose cube_level; the *_total views pin cube_level = 0 (the
  dim equalities stay for the sort-key prefix).
