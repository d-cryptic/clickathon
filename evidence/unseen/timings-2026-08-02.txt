WHERE THE EXTRA TIME WENT — it is NOT mostly the contract step
--------------------------------------------------------------------------------
Phase 2b costs only 2-4 s. The bulk of the increase is phase 2, the load:
18 s -> 35 s on the 850k day. That is 0.168 s/MB against the 0.085 s/MB the
runbook extrapolates from. The load is network-bound, so this number belongs to
the link, not the code — it is the one phase that will differ again on the day.

The "123x the events cost 1.07x the wall clock" claim also no longer holds:
123x the events now costs 1.24x (66 s -> 82 s). Still fixed-cost dominated, but
less so, and the extrapolation should not be leaned on as hard.

A BUG THIS FOUND — tools/unseen-run.sh dies at the contract gate
--------------------------------------------------------------------------------
Line 351 reads $TARGET:

    CONTRACT_ARGS=""
    [ "$TARGET" = cloud ] && CONTRACT_ARGS="-c"

The script sets TARGET nowhere in its own scope (line 276 sets it only inside a
subshell for the load). Under `set -euo pipefail` an unset TARGET is fatal:

    tools/unseen-run.sh: line 351: TARGET: unbound variable

So the advertised one-command path DIES at phase 2b unless TARGET happens to be
exported in the caller's environment. Measured on this tree, first attempt:

    2b SOURCE CONTRACT — is this file what we think it is?
    tools/unseen-run.sh: line 351: TARGET: unbound variable
    -> run aborted after 32 s, no model built, no gate run

Every timing above was taken with TARGET=cloud exported as a workaround. This
file does not own tools/unseen-run.sh (branch fix/contract-gate-runner-agreement
holds it) so the fix is NOT applied here — it is reported.

Note the shape of the failure: the contract gate was wired onto the path on
2026-08-02 precisely because Codex 005 found it was documented but not called.
It is now called, and it is the line that stops the run.
